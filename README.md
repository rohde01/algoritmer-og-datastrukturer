# Algoritmer og datastrukturer

Københavns Universitet · BSc i datalogi-økonomi · Forår 2024, blok 3 · 7,5 ECTS  
Kursuskode NDAA04010U · [Kursusbeskrivelse](https://kurser.ku.dk/course/ndaa04010u)

Design og analyse af algoritmer og datastrukturer med rekursionsligninger, del og hersk, amortiseret analyse, søgetræer, hobe og grådige algoritmer.

## Indhold

| Mappe | Indhold |
| --- | --- |
| `assignments/aflevering-<n>/` | Afleveringer 1–4, `main.tex` og `main.pdf` |
| `notes/erer/` | Noter om rekursionsligninger |
| `notes/exam-prep/` | Eksamensforberedelse, noter og gamle eksamenssæt |
| `materials/` | Kursets eget materiale. Gennemgå før repoet gøres offentligt. |

## Emner

- Rekursionsligninger og køretid
- Del og hersk
- Dynamisk programmering
- Rød-sorte træer
- Disjunkte mængder
- Fibonacci-hobe
- Potentialmetoden
- Grådige algoritmer

## Værktøjer

LaTeX

## Byg

Byg en PDF fra latex med:

```bash
tectonic -Z continue-on-errors main.tex
```
